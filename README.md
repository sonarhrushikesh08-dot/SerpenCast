# SerpenCast
SerpenCast is a Python AI weather assistant that fetches real-time weather data using OpenWeather API and answers user questions using Google's Gemini AI. It combines weather forecasting with conversational AI for an interactive and beginner-friendly project.

 🌦️ SerpenCast

SerpenCast is a simple AI-powered weather assistant built with Python.  
It fetches real-time weather data using the OpenWeather API and answers weather-related questions using Google's Gemini AI. 

🚀 Features

✅ Real-time weather reports  
✅ AI-generated weather explanations  
✅ Clean terminal interface  
✅ Uses OpenWeather API  
✅ Uses Gemini AI API  
✅ Beginner-friendly Python project  

🛠️ Technologies Used

- 🐍 Python
- ☁️ OpenWeather API
- 🤖 Google Gemini AI
- 📡 Requests Library

📦 Installation



Get API keys from:

- 🌤️ OpenWeather
- 🤖 Google AI Studio
